# Smart Waste Management Website

A starter React + Vite dashboard for the Smart Waste Management System.

## Run
1. Install Node.js.
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL shown by Vite.

## Included
- Dashboard
- Live bin status
- Critical/warning alerts
- Responsive sidebar navigation
- Placeholder modules for map, bin management, route optimization, prediction and analytics

The current data is simulated. Next step is connecting FastAPI/PostgreSQL and ESP32/MQTT.
